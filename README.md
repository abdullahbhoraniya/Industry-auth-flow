# Industry Auth Flow

A complete authentication and authorization system built using Node.js, Express.js, MongoDB, and JWT. This project implements secure user authentication with Access Tokens and Refresh Tokens, OTP-based email verification, protected routes, secure session handling, logout from the current device, and logout from all devices.

## Features

- User Registration & Login
- JWT Access & Refresh Token Authentication
- OTP-Based Email Verification
- Protected Routes Middleware
- Secure Password Hashing
- Logout from Current Device
- Logout from All Devices
- Session Management
- MongoDB Database Integration
- REST API Architecture

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Nodemailer
- bcrypt
